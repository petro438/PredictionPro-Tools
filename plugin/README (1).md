# Kalshi Dashboard — WordPress Plugin

Drop this entire `kalshi-dashboard/` folder into `wp-content/plugins/`, activate it, then use `[kalshi_dashboard]` in any page or post.

## File structure

```
kalshi-dashboard/
  kalshi-dashboard.php   ← Plugin entry point (registers shortcode, enqueues assets)
  template.php           ← Dashboard HTML shell
  kalshi-dashboard.css   ← All styles (kd- prefixed, no theme conflicts)
  kalshi-dashboard.js    ← All logic (self-contained IIFE)
  data/
    snapshot.json        ← Auto-generated by the cron job (fallback cache)
```

## Installation

1. Upload the `kalshi-dashboard` folder to `/wp-content/plugins/`
2. Activate in WordPress → Plugins
3. Add `[kalshi_dashboard]` to any page using Gutenberg's "Shortcode" block or Classic Editor

## Connecting to the Kalshi API (required for live data)

The Kalshi API doesn't allow direct browser requests (CORS).
You need the proxy server running somewhere. Two options:

### Option A — Vercel proxy (recommended)
Deploy `server.js` from the main project to Vercel, then add this to your `wp-config.php`:

```php
define( 'KALSHI_PROXY_URL', 'https://your-app.vercel.app' );
```

### Option B — Same-server proxy
If Pressidium gives you Node/shell access, run `server.js` on the server and set:

```php
define( 'KALSHI_PROXY_URL', 'https://predictionpro.com' );
```
(assuming the proxy runs on port 443 via reverse proxy)

## Daily snapshot (for fallback + historical chart data)

Run the cron job from the main project daily to keep `data/snapshot.json` fresh.
Upload the updated `snapshot.json` to `wp-content/plugins/kalshi-dashboard/data/`.

You can automate this with GitHub Actions → SFTP to Pressidium, or add a WP-Cron job.

## Customisation

- **Colors / categories**: edit `CAT_CFG` and `CAT_MAP` in `kalshi-dashboard.js`
- **Sport keywords**: edit `SPORT_KW` in `kalshi-dashboard.js`
- **Styles**: all classes are prefixed `kd-` — safe to override in your theme's `style.css`
- **Page template**: to remove the outer border/padding when using a full-width page template, add to your theme CSS:
  ```css
  .kd-wrap { border: none; border-radius: 0; padding: 0; }
  ```
